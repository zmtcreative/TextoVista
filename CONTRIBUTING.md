# Contributing

Thank you for your interest in this project! Please note that this repository serves as a read-only mirror exclusively for distribution purposes. All active development, testing, and code integration occur in a separate private repository.

Because of this workflow, **Pull Requests will not be accepted at this time**. Any Pull Requests opened in this repository will be closed.

### How to Get Involved

While we cannot accept direct code contributions here, your feedback is still highly valued. If you have found a bug, have a feature request, or need to discuss an aspect of the application, please feel free to open a new report in the **Issues** tab.
